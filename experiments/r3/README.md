# Experimentos R3

Este directorio conserva la evidencia de la verificación por equivalencia funcional.

- `variants/`: configuración de casos diferenciales, entornos, defectos y controles.
- `logs/`: instalación, pruebas del módulo, comparaciones, avisos y análisis estático.
- `results/`: divergencias, construcciones obsoletas, equivalencia acotada, sensibilidad y especificidad.

El conjunto de defectos y la muestra de especificidad deben mantenerse separados. Una migración declarada no equivalente requiere revisión conforme al método antes de clasificarla en el cálculo de especificidad. R3 no registra llamadas al modelo de lenguaje porque no debe invocarlo.
